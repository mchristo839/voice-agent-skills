# Roadmap

The next skills, in order. One ships every week. Want something else? Open an issue.

- [x] **cal-booking**: connect Cal.com so the agent checks real availability and books during the call
- [ ] **crm-sync**: send every call's result (name, number, reason, booked) to GoHighLevel or HubSpot
- [ ] **missed-call-textback**: text anyone whose call was missed or dropped within a minute, with a booking link
- [ ] **outbound-campaign**: call a CSV list with consent checks, calling windows by time zone and a do-not-call list
- [ ] **review-request**: after a good call, text the caller a link to leave a Google review
- [ ] **after-hours**: business hours, holidays and different call flows for after-hours callers
- [ ] **warm-transfer**: hand the caller to a person with a whispered summary, and a fallback when nobody answers
- [ ] **multilingual**: detect the caller's language, switch, and test the agent in each language
- [ ] **voicemail-handling**: detect voicemail and leave a short message that's actually useful
- [ ] **knowledge-refresh**: re-crawl the site on a schedule and show what changed in the knowledge base
- [ ] **vapi-deploy**: the deploy skill for Vapi
- [ ] **elevenlabs-deploy**: the deploy skill for ElevenLabs Agents
